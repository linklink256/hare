# 悬浮窗只跟踪主代理，不响应子代理完成

用户要求：悬浮窗只在主代理任务完成时显示任务完成，子代理完成不用提示。

## 实现

- `ChatFloatingTracker` 在挑选目标会话之前，查询持久化的团队成员归属，将所有子代理会话从候选运行会话中剔除。
- 普通独立会话和团队根领队会话均保留；即使旧数据中一个成员还兼任嵌套团队领队，成员身份依然优先排除。
- 主代理运行时子代理开始/完成，不再抢走悬浮窗目标或使悬浮窗显示子代理的完成状态。只有子代理在运行时不新开悬浮窗；主代理结束时也不需要等待所有子代理。
- 沿用主会话原有生成、审批、错误、完成与展开/关闭行为，不重写完成原因判定；不改系统通知，不改全局 `generationDoneFlow`，不影响 `wait_agent`。
- 对每次运行会话 ID 集合变化使用 `mapLatest` 查询归属，避免独立 Room 名册 Flow 更新滞后时短暂选中刚启动的子代理。现有创建路径在启动子代理任务前已经完成成员持久化。
- 归属仓库保持延迟创建，只在后台悬浮窗跟踪期间使用；无定时轮询，无正文读取。
