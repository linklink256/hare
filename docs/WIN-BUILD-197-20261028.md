# 用 llink-win 编译 debug 197 并安装到独立 debug 包

用户要求：这三条 UI 改动（团队列表标题改成「今天」那种分组样式、团队列表显示主对话的文件夹栏、debug 软件名改成 `debug`）用 **llink-win** 编译。源码改动已在 `0589a3f2`（versionCode 196→197）。

## 构建（llink-win）

链路仍是容器 → Ali → llink-linux → llink-win，未新开隧道、未改系统环境。

- 源码用已核验快照 `results/team-folder-win-debug-20261028/source-197.tar.gz`（SHA256 `8fde1f87…`，对应 commit `0589a3f2`）。独立校验：1711/1711 文件与 git 一致，无 `.git`、`local.properties`、keystore、`results/`、用户设置或数据库。
- 工具链全部便携安装到 `C:\Users\llink\build-workspace\tools`，**未改系统 PATH/注册表**：Temurin JDK 21.0.12.1+1、cmdline-tools 16111833、platforms android-37.2、build-tools 37.0.0、NDK 28.2.13676358、CMake 3.22.1、Node 24.22.1 + pnpm 10.33.4（`web-ui` 需要）。
- 命令：`gradlew.bat :app:assembleGithubDebug --no-daemon "-Dorg.gradle.jvmargs=-Xmx5120m -XX:MaxMetaspaceSize=1024m -Dfile.encoding=UTF-8"`，用 Windows 计划任务脱离 SSH 会话运行。
- 结果：**BUILD SUCCESSFUL in 29m**，退出码 0，310 tasks（306 executed）。
- 首次尝试失败（`Unknown command-line option '-X'`）：JVM 参数被 `cmd` 拆参后当成 Gradle 选项；改成 `.bat` 里整体加引号后成功。

两个快照缺口（都不是这次改动引入的，但对以后远程编译重要）：

1. tarball 里子模块 `material3/material-color-utilities/` 是空目录，而 `:material3` 需要它的 `kotlin/` 源码 → 从容器用 `git archive` 导出该子模块 commit `5b3618b1`（383 文件）补上。
2. `:web:preBuild` 依赖 `web-ui` 的前端构建 → Windows 侧便携装 Node/pnpm 后执行 `pnpm install`。

## 签名与安装

Windows 自动生成了它自己的 debug keystore，与平板上已装 debug 包的 key（`f44f36d6…`）不同。为在**不清数据、不卸载**的前提下更新，在容器侧用既有 `/root/.android/debug.keystore` 重新签名：

- `zipalign -p -f 4` → `apksigner sign`（v2 开启）。
- 重新签名前后逐条比较 1368 个 zip 条目：**CRC/大小差异 0 行**，只有签名块变化，payload 未改。
- 重新签名后 `apksigner verify` 通过，证书 SHA-256 与已装 debug 包一致（`f44f36d6…`）。
- 私钥始终留在容器，未传到 Windows。

安装：`adb install -r`（Incremental Install, 389 ms），`me.rerere.rikkahub.debug` **196 → 197**。
